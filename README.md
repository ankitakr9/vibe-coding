## 🤖 AI-Assisted Development Workflow

AI is an assistant in my development process, not a replacement for understanding the code.

My workflow:

1. **Idea & Planning** – Identify an idea and define its requirements.
2. **Prompt Engineering** – Create detailed prompts for the AI coding assistant.
3. **Code Generation** – Use Google AI Studio (Gemini) to accelerate implementation.
4. **Code Review** – Review and understand the generated code.
5. **Customization** – Modify features, UI, and application behavior.
6. **Debugging & Testing** – Identify errors and improve application quality.
7. **Documentation** – Maintain project-specific documentation.
8. **Version Control** – Manage source code using Git and GitHub.
9. **Continuous Learning** – Explore new concepts and improve development skills.
